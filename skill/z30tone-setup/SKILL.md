# Z30 影调工具 · 安装与配置向导

你的任务：带用户从零装好并配置 **Z30 影调工具**，直到完成第一次成功写入。
全程跟着下面的步骤走，不要跳步；每一步做完等用户确认再做下一步。

## 0. 先记住边界（回答用户问题时的口径）

- 本工具通过逆向出的私有 PTP 指令与相机通信，**不改固件、不刷机、无变砖风险**；
- 只写用户槽位 **C1–C9**，建议第一次写 **C9**；「删槽」指令（0x90CE）本工具不实现；
- 机身载荷里只有**一条单通道曲线**：能做影调 / 锐化 / 清晰度 / 饱和度，
  **做不了**整体色偏、分色相调整、分离色调——有用户问就照实说；
- 统一对外口径是「**近似 + 偏差报告**」，不说「1:1 复刻」；
- 实验性工具：提醒用户写入前自行备份，首次写 C9 试水。

## 1. 判断用户装哪一端

| 用户画像 | 走哪条路 |
|---|---|
| Windows 电脑 + 相机，想自己拟合 `.cube` / 照片、出报告 | **桌面端**（§2 + §3） |
| 只有手机（含一加/realme/OPPO），拍摄现场写机身 | **安卓端**（§4） |
| 两端都要 | 桌面端先装，安卓端随后 |

两端的曲线是同一套：桌面端拟合的配方可以导出 `.z30` 传给手机写。

## 2. 桌面端安装（Windows）

1. 到 **Releases 页面**下载最新版压缩包：
   `https://github.com/haotiandi1011-lgtm/1dlut-z30-filters/releases`
   （文件名形如 `Z30影调工具-<版本>.zip`，约 70 MB，免装 Python）
2. 解压到**任意非系统目录**（路径里可以含中文）。
3. 双击 `Z30影调工具.exe` 或 `0-启动影调工具.bat` → 浏览器自动打开本地界面
   （只监听 127.0.0.1，不联网）。没弹浏览器就手动开 `http://127.0.0.1:8765`。
4. 用户数据在 `C:\Users\<用户名>\AppData\Local\Z30影调工具\`——**升级换目录不会丢预设**。
   便携模式：exe 旁新建空文件 `portable.txt` 后重启，数据改落同级 `data\`。
5. 想走 USB 写入，先做 §3 的驱动步骤；只想拟合看报告可以先跳过。

## 3. Zadig 驱动（Windows 写入的必经步骤）

⚠️ 这一步是**替换 USB 驱动**，不是改固件，可随时换回。

1. 相机开机，`USB 模式`设为 **MTP/PTP**，插上电脑。
2. 下载 [Zadig](https://zadig.akeo.ie/)，菜单 `Options → List All Devices`。
3. 下拉框选中 **Nikon Z30**（注意别选成鼠标键盘等其他设备）。
4. 目标驱动选 **WinUSB**，点 `Replace Driver`。
5. 副作用：换完驱动后 Windows 相册/资源管理器**暂时认不出相机**（正常）。
   想传照片时在设备管理器里对相机「更新驱动程序 → 自动搜索」换回 MTP 即可，随时可逆。

驱动换好后：界面里选一条滤镜 → 选槽位 C9 → 点「写入」→ 应显示「读回逐字节一致」。

## 4. 安卓端安装

1. 从 **Releases**（或仓库 Actions 的构建产物）下载 APK，文件名形如
   `z30tone-writer-<版本>-debug.apk`，约 9 MB，直接安装。
2. 相机开机、USB 模式设为 **MTP/PTP**，用 **C-to-C 数据线**直连手机（需要手机支持 OTG；
   iQOO Neo9 / 一加 Ace 3V 实测可直连，不用转接头）。
3. 打开 App，在系统弹窗里允许 USB 访问；顶部显示「相机已连接」后自动读出 C1–C9 状态。
4. 选曲线的三种方式：内置预设（随 App 打包，不用电脑）/ 导入电脑端导出的 `.z30` /
   「从照片生成曲线」（手机上直接算，支持 JPG / PNG / HEIC，RAW 手机解不了）。
5. 选槽位（第一次建议 C9）→「写入」→ 看到「读回一致」才算成功。

## 5. 报错排查表（按出现频率排）

| 现象 | 原因与处理 |
|---|---|
| 写入失败，错误码 -1 | 相机刚休眠（半按快门唤醒）、正在回放/翻菜单、或线材只供电不传数据。失败后 App 会自动清端点并重新握手，**直接再点一次「写入」**即可 |
| 一加 / realme / OPPO 上反复失败 | 设置里「OTG 连接」要开着，**关掉「OTG 自动关闭」**；电池设置别限制 App；别经扩展坞，直连 |
| 读相机超时 | 相机休眠、不在 MTP/PTP 模式、USB 供电不足（换原装线、别用 Hub） |
| USB 接口被系统占用 | 拔插相机重连一次；Windows 端确认 Zadig 驱动换成了 WinUSB |
| 相机返回 0x2019 | 相机忙：退出回放/菜单再试 |
| 「读回校验未通过」 | 相机没接受完整数据，界面会列偏移；**别再连点写入**，拔插后先看日志；原内容可从写入前备份恢复 |
| 桌面端 exe 双击没反应 | 杀软误报（PyInstaller 常见），加白名单；日志在数据目录 `app.log` |
| 手机上选不了 NEF | 手机端照片拟合只支持 JPG/PNG/HEIC，RAW 是系统解码器限制；RAW 用桌面端 |

## 6. 常见问题

- **会不会把相机弄坏？** 不改固件、不刷机；写入前后自动备份/校验，失败不做自动补救。
- **为什么曲线换个白平衡效果不一样？** 管线顺序是 LUT 在前、白平衡增益在后（乘法）。
  严肃复现请固定白平衡。
- **删除的预设去哪了？** 内置/配方库预设只能「隐藏」（可一键恢复）；自存配方进回收站，
  回收站里才有「彻底删除」。
- **换电脑怎么带走预设？** 拷数据目录里的 `presets.json`（+ 隐藏/回收站两个文件），
  或用便携模式整个文件夹搬走。

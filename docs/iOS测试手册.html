Z30 影调
iPhone 版

给帮忙测试的朋友：怎么装、怎么用、要测什么
一句话说明这是干什么的
它帮你在手机上做一条「明暗曲线」——可以从 121 套现成的里挑，也可以拿一张照片算出来——
然后导出一个约 1 KB 的小文件，或连上相机 Wi-Fi 直接写进相机的 C1–C9 槽位。

默认只读：只有你点「写入」并确认之后，才会改动相机里的那一个槽位。
Wi-Fi 写入需要相机先和电脑配对过一次，详见第 11 节；导出这条路径不需要配对。
版本 v0.3.0（测试版）· 仅用于受邀请的测试
文档更新：2026 年 11 月

1. 你需要准备什么

东西要求
iPhone系统 iOS 16 或更新。查看方法：设置 → 通用 → 关于本机 → 看「软件版本」
Windows 电脑Win10 / Win11 都行，能联网
数据线能传数据的苹果线。只能充电的线不行（这类线插上电脑没反应）
Apple ID就是你平时在 App Store 下载东西用的账号，免费账号就行，不用花钱
时间第一次装大约 10 分钟，之后测试约 15 分钟
先说清楚代价 用免费 Apple ID 装的 App，苹果只允许用 7 天。到期后 App 打不开、图标变灰，不是坏了， 连电脑用同样的方法再点一次开始就行，不用卸载重装。这是苹果的规定，绕不过去。

2. 怎么装到手机上

2.1 先下载两个东西

1
安装包：我发你的 Z30Tone-unsigned-ipa（文件名以 .ipa 结尾）。先存到电脑桌面，别放太深的文件夹。
2
安装工具 Sideloadly：浏览器打开 sideloadly.io，下载 Windows 版并安装。免费，不用注册。

2.2 把手机连上电脑

3
用数据线把 iPhone 插到电脑。手机屏幕会弹「要信任此电脑吗」，点信任，然后输入你的锁屏密码。
4
打开 Sideloadly。左边应该能看到你的手机名字。
如果显示「No device found」：换一根线、换一个 USB 口，或者把手机解锁后再看。

2.3 装进去

5
把 .ipa 文件直接拖到 Sideloadly 窗口里；或者点窗口里那个蓝色的 IPA 图标去选文件。
6
在 Apple ID 那一栏填你的苹果账号邮箱。
7
点右下角的 Start。会弹窗要密码，填你的 Apple ID 密码。
8
等进度条走完（大约 1–2 分钟）。手机上会出现「Z30 影调」的图标。
如果开了「双重认证」（大部分人都开了） Sideloadly 会让你在手机上输入收到的验证码，按提示做就行。它不会保存你的密码。

2.4 第一次打开前，必须做这两件事

不做这两步，App 一定打不开 这不是软件的问题，是苹果对「非 App Store 来源」的强制要求。

第一步：信任开发者

设置 → 通用 → VPN 与设备管理 → 在「开发者 App」下面找到你的 Apple ID（邮箱）→ 点进去 → 点信任。

第二步：打开开发者模式（iOS 16 及以上）

设置 → 隐私与安全性 → 拉到最下面 → 开发者模式 → 打开 → 手机会要求重启 → 重启后解锁，会再问一次，点打开。

找不到「开发者模式」？ 说明手机还没连过开发工具。先把手机连上电脑、打开 Sideloadly 一次，这个选项才会出现。

2.5 以后又打不开了怎么办

七成是 7 天到期了。把手机连电脑，打开 Sideloadly，重新拖一次 ipa、点 Start 即可， 不用先卸载。卸载会把你存的配方一起删掉。

整个 App 就是一页，从上往下滑，一共八块：

这一块干什么的
相机连接手机连上相机 Wi-Fi 后点「连接」。你的相机没做过配对，这一步会提示「相机拒绝了这台主机」，属预期（见第 11 节）

4. 测试一：预设库

操作

1
找到「内置预设库」这块，点右上角的「挑选」。
2
弹出一个列表。顶部有搜索框，输入「胶片」试试。
3
随便点一条，比如「胶片 01 · 提亮」。
4
再打开一次预设库，在某一条上向左滑，看有没有「隐藏」和「改名」。
5
点左上角「看隐藏」，找到刚才隐藏的那条，点「恢复」。
合格标准
  • 列表里一共 121 条，按「内置影调 / 胶片 / 电影 / 风光 / 暗调 / 街拍 / 日系 / 人像 / 黑白」分组
  • 搜「胶片」能筛出那一组
  • 点一条之后弹窗自动关掉，主界面上显示这条名字
  • 「隐藏」之后它从全部列表消失，但「看隐藏」里能找到，点恢复又回来
  • 改名之后显示的是新名字（提示里会说「只改显示名，id 不变」，这是对的）

5. 测试二：用照片生成曲线

操作

1
点「从照片生成曲线」里的「选一张参考照片」。
2
从相册选一张。建议选明暗层次完整的（有暗部、有中间调、有高光）， 别选大白天拍纯白墙、或夜里大片纯黑的照片。
3
等 1–3 秒。
4
看下面的数字和曲线，然后点「存为配方」。
合格标准
  • 出现「尺寸 / 耗时 / 贴合误差」三个数字
  • 「贴合误差」两个数字通常都在 3 以内（越小越贴合）
  • 出现一张曲线图：橙色的虚线是目标，实线是结果，两条应该贴得比较近
  • 下面有一条带颜色的建议（绿色=很好，黄色=要留意，红色=不建议用）
  • 点「存为配方」后，下面的「配方」里会多一条
耗时多久算正常 4 秒以内都能接受。如果超过 10 秒，告诉我你的手机型号，我来优化。
如果提示「这张图解不开」 相机的 RAW 文件（.NEF）是解不开的，这是苹果系统的限制。换成 JPG 或 HEIC 再试。

6. 测试三：拖动对比

操作

1
在「照片对比」里点「选一张照片来看效果」，可以选和第 5 节同一张。
2
照片上会出现一条白线和一个圆点。手指按住画面左右拖动。
3
点「导出预览图」，选 PNG，看能不能存进「照片」。
合格标准
  • 白线跟着手指走，左边是原图，右边是套了曲线的
  • 拖动过程不卡顿
  • 换一条预设之后再回来，对比效果会跟着换（不用重新选照片）
  • 导出的图能存进相册，打开看明暗确实变了
这里最容易误解 曲线只改明暗，不改颜色。所以如果你选的预设本身靠「色偏」才像某种风格， 对比图里只会看到明暗变化，颜色不会变——这不是 bug。

7. 测试四：导出文件

操作

1
确认底部那条显示的是你想导出的配方名。
2
点「导出 .z30」。
3
在弹出的面板里点「保存 / 分享」 → 选「存储到文件」 → 存到「我的 iPhone」里。
4
打开手机自带的「文件」App，找到刚才存的文件。
合格标准
  • 「文件」App 里能看到一个 .z30 结尾的文件
  • 大小约 1 KB（如果显示 0 字节或几百 KB，都不对）
  • 文件名就是你给的配方名
这个文件干什么用 把它发到安卓手机或电脑上，用那边的 App 打开，就能写进相机的 C1–C9。 这一版 iPhone 也能连相机 Wi-Fi 直接写，但需要先配对（第 11 节说明为什么你暂时用不了）。 导出这条路不需要配对，随时可用。

8. 测试五：配方管理

在「配方」这块，每一行右边有三个点「⋯」，点它会出现菜单。

  • 改名：改完列表里显示新名字，曲线不变
  • 移入回收站：这一行从列表消失，但点右上角「回收站」还能找到
  • 回收站里：可以「恢复」，也可以「彻底删除」；右上角「清空」会全部删掉（会再问一次）
彻底删除是真的删 和电脑上的回收站一样，清空之后就找不回来了。测试时随便删，但别删你打算留着的东西。

11. 这个版本不能做什么

写在这里，免得你以为是坏了：

  • Wi-Fi 直连写入需要先配对。这一版已经支持通过相机 Wi-Fi 写 C1–C9， 但它用的主机身份来自一次电脑端配对，只对那台相机有效。 你的相机没做过这个配对，所以点「连接」会提示「相机拒绝了这台主机」—— 这是预期结果，不是你操作错了。要写入请走「导出 .z30」， 或者等 0.3.1 把相机端的 PIN 配对做进来。
  • 不能改色偏、饱和度、分色相。相机里那条曲线只作用于明暗，三个颜色通道用的是同一张表， 数学上就造不出颜色差异。
  • 不能打开 RAW。只能读 JPG / PNG / HEIC。
  • 不会给「还原度百分比」。单张照片没有标准答案，那个数字是编的。 它只给「影调贴合误差」，单位是 8 位色阶，越小越贴合。

12. 你的数据在哪

  • 配方存在你自己手机里，不上传任何服务器，App 不联网。
  • 卸载 App 会连配方一起删掉。要留着就先导出成 .z30 文件。
  • 相机完全不会被改动——这个版本里根本没有写相机的功能。
这份手册对应 Z30 影调 iPhone 版 v0.3.0（测试版）。
如果你在别处看到「一键复刻某某滤镜」之类的说法，那不是这个项目——本项目只做影调近似， 并且会明说哪些做不到。
